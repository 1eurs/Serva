Serva Station Field Guide

Getting a café's Wi-Fi receipt printer talking to Serva Station in one visit — without the router password, without a laptop, and without a call to the office.

KIT

What to bring, what to ask

Assume you will not get the router password. Most café owners don't have it, and the ones who do can't find it. Everything in this guide works without it.

  • The station tablet, charged, with Serva Station installed and the staff login ready.
  • A spare paper roll — you will print more test slips than you expect.
  • A paperclip, for reset pinholes on Wi-Fi modules.
  • Pen and this guide's record card, or your phone to fill it in.

Ask the café before the visit: make and model of the printer, and whether it is Wi-Fi or Bluetooth. If they can photograph the label on the underside, that alone saves ten minutes on site.

01

Write down the tablet's own address first

Do this before you open Serva Station. Every decision later in this guide is a comparison against this number, and you cannot make it from memory.

Join the café Wi-Fi, then: Settings → Wi-Fi → tap the connected network → Advanced / Network details.

Write down the IP address and the gateway. A typical café looks like this:

Tablet — write this down
IP address192.168.100.240
Gateway192.168.100.1 — the router
Prefix length24 — the default

The part that matters is the first three numbers: 192.168.100. That is the café's network. Anything sharing those three numbers can be reached; anything that doesn't, can't.

02

Scan, and hope you're done

Most installs end here, in about ten seconds.

In Serva Station: printer setup → Scan. The app asks the network for printers, then walks all 254 addresses on the café's range.

If the printer appears and the line underneath says “Answered as a printer”, that is proof rather than a guess — the printer replied over ESC/POS, not merely left a port open. Tap it, run the test print, and go to Before you leave.

Found it, but it says “out of paper”

That is still the right printer, and the status channel is working. Load a roll, close the cover properly until it clicks, and scan again.

If the list is empty, the printer is almost certainly powered on and working — it is just not on the same network as the tablet. Carry on to step 3.

03

Make the printer tell you its address

Every thermal printer will print its own settings if you ask it correctly. This takes fifteen seconds and removes all the guesswork.

Switch the printer off. Hold down the FEED button. Switch it on while still holding. Release when it starts printing.

You get a self-test slip. Somewhere on it is the network block:

SELF TEST
Mode
Infrastructure
SSID
R418
IP
192.168.1.87
Mask
255.255.255.0
Gateway
0.0.0.0
Port
9100

Write the IP down next to the tablet's. If the slip prints no address at all, or shows 0.0.0.0, the printer never joined the Wi-Fi — skip to step 6.

If FEED gives you nothing

Some printers with a bolted-on Wi-Fi module put the button on the module rather than the printer, and a few Epson models use a separate push button on the interface board — hold that for more than three seconds with the printer already on, and it prints a network status sheet instead.

04

Compare the two addresses

This is the whole diagnosis. You now have two numbers; only their first three parts matter.

First three match

Tablet 192.168.100.240
Printer 192.168.100.87

Same network. The address is not your problem — the printer is asleep, has dropped off the Wi-Fi, or the router is separating wireless clients from each other.

Power-cycle the printer and scan again. If it still doesn't answer, go to Bluetooth.

First three differ

Tablet 192.168.100.240
Printer 192.168.1.87

The printer is holding a fixed address from wherever it was installed before. Both are on the same Wi-Fi, but they are in ranges that cannot talk to each other.

This is the common case. Go to step 5.

Check this before step 5

The prefix fix only works when both addresses start with the same first two numbers — in practice, when both begin 192.168.

If the café is on 10.0.0.x and the printer says 192.168.1.87, no tablet setting can bridge that. Go straight to step 6 or step 7.

05

Widen the tablet's reach

One field on one screen. No router, no laptop, and nothing on the printer changes.

On the tablet: Settings → Wi-Fi → long-press the café network → Modify network → Advanced options → IP settings → Static.

Keep the address the tablet already has. Change only the prefix length, from 24 to 16:

Static IP — tablet
IP address192.168.100.240 — leave exactly as it was
Prefix length16 — this is the only change
Gateway192.168.100.1 — the café's router
DNS 18.8.8.8
DNS 28.8.4.4

A prefix of 16 stretches the tablet's idea of “my network” from 192.168.100.x to the whole of 192.168.x.x. The printer at 192.168.1.87 falls inside it, and so does the router — so printing and internet both keep working.

If Save is greyed out or bounces

  • Don't change the IP address. Android refuses a static config whose gateway sits outside the network the address and prefix describe. Leaving the address alone avoids this entirely — it is the single most common reason this screen won't save.
  • Fill every field. A blank DNS 2 will block the save on many builds.
  • The prefix field wants 16, not 255.255.0.0.
  • Re-enter the Wi-Fi password if the form asks for it.
  • Toggle Wi-Fi off and on after saving, so the new settings actually apply.

Then connect the printer

Open a web page first, to confirm the tablet still has internet. If it doesn't, the gateway or DNS is mistyped and nothing else will work.

In Serva Station, tap Enter the address myself and type the printer's address from the slip:

Serva Station — manual address
Printer address192.168.1.87

Scan won't find it on its own — the app sweeps the 254 addresses around the tablet's own, which is still the 192.168.100.x range. The manual address is the right tool here, and it will connect now.

Run the test print.

You have left a landmine — record it

A static IP lives on that one tablet. If the café replaces the router, changes its address range, or the tablet is swapped, printing stops and the next person will have no idea why.

Write it on the record card, and flag the café for a proper fix: get the printer onto DHCP, or move it to Bluetooth on the next visit.

06

Put the printer back on automatic

The durable fix. Do this instead of step 5 when you have physical access and a few minutes, because it leaves nothing behind to break.

You are looking for a small push button or pinhole on the network module — near the LAN socket or the antenna, not the FEED button on the front.

  • Hold it for more than 3 seconds with the printer already on: prints a network status sheet showing the real settings.
  • Power the printer on while holding it, and keep holding for about 10 seconds: resets the network settings to factory defaults, which means DHCP.

Then power-cycle the printer, wait a minute for it to take an address from the café's router, and scan again in Serva Station. It will now be on the café's own range and the app finds it with no manual address at all.

When there is no settings page to find

Older printers are often retrofitted with a third-party Wi-Fi module — a genuine Epson behind a no-name adapter, for instance. These usually have no web page, no configuration app and no reset that you can reach over the network. Only the print port answers.

Don't spend twenty minutes hunting for a settings screen that doesn't exist. Use the pinhole if there is one; otherwise fall back to step 5 or Bluetooth.

After a factory reset the module may come up broadcasting its own Wi-Fi network — something like Printer_A1B2. If it does, join it from the tablet and open the address printed on the status sheet (commonly 192.168.4.1 or 10.10.100.254). From there, point it at the café Wi-Fi and set it to automatic. Remember to put the tablet back on the café network afterwards.

07

Bluetooth, when the network won't cooperate

Not a defeat. A Bluetooth printer has no address, no range and no router — there is nothing left that can go stale.

If the printer supports Bluetooth, this is often the better install even when the network route is available.

  1. Pair the printer in Android Settings → Bluetooth. Serva Station never scans for devices, so it must be paired in system settings first.
  2. In Serva Station, choose the Bluetooth printer option and pick it from the paired list.
  3. Run the test print.

Everything above the connection is identical — the queue, the receipt layout and the paper-out warnings all behave exactly as they do over the network.

—

Don't waste the visit on these

  • “Search wider.” It takes about a minute and almost never helps. It tries other common ranges, but the tablet has no route to them, so the packets go to the router and are dropped. Use the FEED slip instead — it is faster and it actually answers the question.
  • Asking for the router password. Changing the router's range would fix this, but you usually can't get in, and you should not be reconfiguring a café's network to install a printer.
  • Typing the printer's address before checking the prefix. If the tablet is still on prefix 24 and the printer is on another range, the app will say “Nothing answered at that address.” That message is misleading: something is there, the tablet just has no way to reach it. Do step 5 first.
  • Hunting for a web page on the printer. Many of these have none at all. Check the status sheet, not your browser.
—

Before you leave the café

The install isn't finished when a test slip prints. It's finished when it will still print tomorrow morning.

  • Test print from Serva Station — not from anywhere else — and check it cuts cleanly.
  • Send a real order through and confirm the ticket reaches the counter.
  • Confirm the tablet still loads a web page, so orders can actually sync.
  • Turn off Android's battery optimisation for Serva Station when it offers, or the app will be killed mid-shift.
  • Leave the tablet on a charger, and show staff the Serva notification — tell them not to swipe it away and never to use Force stop.
  • Restart the tablet and confirm the station comes back on its own.
  • Load a fresh roll and leave the spare where staff can find it.
  • Fill in the record card below.

Escalate rather than improvise

Call the office before leaving if: the printer never appears on any route and has no Bluetooth; the café's range and the printer's range share no first number; or the printer answers but prints blank or garbled slips.

Do not change the café's router settings, and do not factory-reset a printer the café doesn't own.

The single number that decides almost every install is the first three parts of the printer's address, compared against the tablet's. Get the FEED slip early and the rest of this guide is a short lookup.
